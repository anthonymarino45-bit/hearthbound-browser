# Hearthbound browser playtest

This repository contains the playable Web build, not the Unity project source.

Enable GitHub Pages from the main branch, root folder. Open the resulting website in desktop Chrome. Do not open index.html directly from a downloaded folder.

Choose a leader and enter the village. One player chooses **Host co-op** and shares the join code. The other opens the same website and chooses **Join friend**. Each player runs their own settlement. Keep the host's page open and visible.

Click a villager, then press E to control them. L selects your crowned leader. WASD moves; Tab returns to settlement view. Scroll zooms; hold middle mouse and drag to rotate and tilt; hold Shift with WASD to pan faster in settlement view. B toggles construction; 1–8 selects a building. Existing controller support has not yet been verified in the browser.

The host can save both settlements in their browser. Leave co-op before loading. Clearing browser data removes browser saves. This is an early two-player foundation playtest; there is no host migration.

The November 24 environment update adds wooded hills, a river, textured ground, wind-blown foliage, and Kimodo idle/walk animation for all 16 race/body models. Grounding is corrected and both co-op players retain their chosen leader race.

Two isolated Chrome clients passed real Relay hosting/joining, separate settlements, selected races, direct control, camera input, save and restore with zero errors on November 24, 2026. The public address is https://anthonymarino45-bit.github.io/hearthbound-browser/ . A test between separate physical computers remains useful.

The camera and orders update uses a normalized wheel step for 20 percent zoom per detent. In settlement view, left-click your unit and right-click walkable ground to move it; duties resume on arrival. Middle-mouse drag orbits. Tab returns from direct control and keeps keyboard focus inside the game. Both players must refresh before joining protocol hearthbound-6.
